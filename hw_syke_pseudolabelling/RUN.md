# Запуск эксперимента SYKE ZooScan

## Данные

Скачай `SYKE-plankton_ZooScan_2024.zip` на вкладке **Data** в Fairdata Etsin.
Ноутбук читает изображения и авторское разбиение из ZIP или распакованной
папки с `class_splits/` и `images/`.
[Датасет SYKE ZooScan 2024](https://etsin.fairdata.fi/dataset/6fa42787-9772-41a5-a6fc-0dde489ed908/data)

## Полный запуск на Kaggle

Импортируй `syke-plankton-class.ipynb` в Kaggle. Загрузи ZIP как Dataset и
подключи его через **Add Input**. Ноутбук ищет архив или распакованную папку
в `/kaggle/input`. Если найдено несколько вариантов или архив переименован,
укажи точный путь в `ARCHIVE` в ячейке настроек.

Выбери **GPU**, включи **Internet** для загрузки весов ImageNet и оставь
`SMOKE = False`. Нажми **Run All**. Ноутбук подготовит одно разбиение и
последовательно выполнит три прогона обеих моделей с seed 42, 43 и 44.

## Короткая проверка

В Kaggle выставь `SMOKE = True` и нажми **Run All**. Достаточно CPU. Ноутбук
возьмёт подвыборку, использует случайные веса и проведёт по одной эпохе на
стадию. Метрики этого режима предназначены для проверки кода.

Для локальной проверки с Python 3.12 выполни команды из корня репозитория.

```sh
python -m pip install torch==2.15.0 torchvision==0.29.2 --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r hw_syke_pseudolabelling/requirements.txt
python -m notebook
```

Открой ноутбук из папки `hw_syke_pseudolabelling/`. В ячейке настроек поставь
`SMOKE = True` и укажи абсолютный путь к загруженному ZIP в `ARCHIVE`. На
Windows можно задать его как raw-строку, например
`ARCHIVE = r"C:\Downloads\SYKE-plankton_ZooScan_2024.zip"`. Запусти все ячейки.

## Выходные файлы

В Kaggle результаты сохраняются в `/kaggle/working/outputs/full/experiment_*/`.
Локальный короткий запуск пишет в `outputs/smoke/experiment_*/` в рабочей
папке ядра. После каждого seed в `comparison.csv` добавляются две строки.
После третьего прогона ноутбук выводит сводку и сохраняет
`aggregate_tests.csv`, `conclusions.txt` и два итоговых графика. В каталоге
каждой модели и seed сохраняются кривые train loss и Validation Macro F1,
матрица ошибок, метрики по классам, предсказания, псевдометки и веса.

## Результаты полного запуска в Kaggle

Средние по seed 42, 43 и 44 получены при полном запуске на Tesla T4 до
форматирования кода. В ноутбуке сохранены вывод с метриками по всем seed,
итоговые графики и статистические тесты этого запуска. Их можно посмотреть
сразу при открытии файла.

| Модель | Macro F1 до | Macro F1 после | Разница, п.п. | p после поправки Холма |
|---|---:|---:|---:|---:|
| ResNet18 | 0,9412 | 0,9360 | −0,53 | 0,300 |
| EfficientNet-B0 | 0,9113 | 0,9244 | +1,31 | 0,0006 |

У EfficientNet-B0 прирост относится ко всей стадии дообучения. Финальная
ResNet18 опередила EfficientNet-B0 на 1,16 п.п. в среднем, с `p = 0,300`
после поправки Холма. Тесты используют общий набор тестовых изображений
при фиксированных обученных моделях.

Лицензия в корне репозитория относится к коду. Датасет доступен на условиях,
указанных в карточке Fairdata Etsin.
