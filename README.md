## Классификация зоопланктона и псевдолейблинг

Обучить ResNet18 и EfficientNet-B0 классифицировать объекты на снимках SYKE
ZooScan 2024. Для обеих моделей постепенно усилить аугментацию, поэтапно
разморозить слои с разными learning rate и дообучить модель на уверенных
псевдометках. Сравнить тестовый Macro F1 до и после дообучения на общем
разбиении. Повторить сравнение с тремя seed и оценить разницу парными
статистическими тестами.
